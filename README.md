# JOM-PADAN-JOM-BINA-AYAT-GRAMATIS
“Jom Padan, Jom Bina!” ialah aktiviti digital interaktif Bahasa Melayu Tahun 4. Murid memilih dan memadankan gambar Siapa, Buat Apa dan Keterangan berdasarkan situasi gotong-royong. Selepas padanan tepat, murid membina lima ayat gramatis, menyemak ayat dan menghantar jawapan secara digital.
